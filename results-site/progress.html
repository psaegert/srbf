What is counted

Each small block is one budget, from the smallest on the left to the largest on the right.

Results. Every problem set is run twice at each budget. A run counts once every problem in it has a result, and a block fills up as its runs finish. The count is the finished runs out of all planned runs.

Times. A block fills once the time per problem at that budget has been measured on our timing workstation. The count is the measured budgets out of all budgets.

A budget appears in the explorer's plots once every problem set has one finished run at that budget. It appears on the time axis once its time is measured. A method with all results and all times in is listed as finished. A scheduled method can already be run by srbf but has no results here yet.
